Fotos sem feed

Uma landing page com acesso por código para entregar as fotos do Unoesc Day sem expor alunos menores de idade.

como eu pensei

  1. Problema

    Muitos alunos no evento eram menores de idade. Publicar as fotos num feed aberto exporia a imagem deles.

  2. Pergunta

    Como entregar a foto de cada aluno sem mostrá-la para mais ninguém?

  3. Decisão

    Um código individual: cada aluno vê só as próprias fotos, sem precisar se cadastrar.
